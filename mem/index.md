# Project Memory

## Core
Não usar imagens "engessadas" em molduras quadradas isoladas. Imagens devem ser integradas ao design (pessoa recortada/sangrando no fundo, cor sólida ao lado, conteúdo sobreposto), nunca com texto em inglês ou screens com fake UI.
Sempre português. Adicionar efeitos visuais (parallax, fade-in, scroll reveal) para deixar elegante.
Paleta: navy escuro (#0a1428) + dourado (hsl(var(--gold))).
